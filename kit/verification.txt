LIMITES
Les tests simulés ne valident pas Hammerspoon, l’IPC, les applications ou les permissions réelles.
Les scripts n’ont pas installé Homebrew ou une application et n’ont pas modifié ton Mac.
Les presets Ghostty suivent les options officielles consultées ; leur rendu et le parsing natif restent à tester sur le Mac.
Les contrôles d’application Darwin, version macOS et Apple Silicon sont à confirmer sur la machine cible.
Les essais de fenêtres, clavier français, écrans, démarrage, consommation et retour arrière figurent dans le PDF.
Un Brewfile ne verrouille pas les versions des applications.
Le modèle Nix n’a pas été évalué ou construit ici : absence de Nix. Identité et lock doivent être définis sur le Mac.
Les branches apply/restore des effets yabai restent à tester nativement ; aucun changement root automatisé.
Le modèle nix-darwin est préparé et non évalué ; les tests du prompt/checklist doivent être exécutés par Claude Opus sur le Mac.
Aucune évaluation A/B du prompt ni exécution de Claude Code /goal effectuée ici. Version du client et capacités UI à vérifier sur le Mac.
