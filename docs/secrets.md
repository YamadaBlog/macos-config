# Secrets and personal data

**Never in this repo**: tokens, SSH/GPG keys, passwords, histories (shell, Atuin, clipboard, Claude), sessions, app databases.

| Data | Location on the machine | How to provide it |
|---|---|---|
| Raycast local token | `~/.config/raycast/aster-endpoint.json` | regenerated by Raycast; do not copy |
| Raycast settings | `.rayconfig` export (Raycast > Settings > Advanced > Export), **password-protected** | keep outside Git (private folder, USB key, vault) |
| SSH keys | `~/.ssh/` | restore from backup or regenerate |
| GitHub auth | `gh auth login` (macOS keychain) | redo on a new machine |
| Tailscale | Tailscale account | sign in again in the app |
| Claude Code | account (`claude` → `/login`); `~/.claude/` except `settings.json` stays private | sign in again |
| Lunar API key | `fyi.lunar.Lunar` domain (`apiKey`) | `defaults export` to a private location; never in Git |
| Stats device id | `remote_id` | stripped automatically on capture |
| Homebrew tap trust | `~/.homebrew/trust.json` | regenerated when the tap is installed |
| Atuin history | `~/.local/share/atuin/` | data backup, not Git |
| Wallpaper images | `wallpapers/*.png` | third-party images, not published (unknown rights) |

For a secret a config needs: put it in an ignored file (`*.secret`, `*.env`, `secrets/`) or in the keychain
(`security add-generic-password`), and reference only its **name** in the repo.

Guard rail: `scripts/sync.sh` refuses to copy a file matching a secret pattern (token, password, api_key…).
Before each commit: `git diff --cached | rg -i 'token|secret|password|api.?key'`.

## Private export folder (outside Git)
`~/.local/share/macos-config-private/` (mode 700): Lunar (with and without API key), Terminal profiles, Raycast export.
It is on **the same disk** as everything else: until Time Machine is configured, copy it to encrypted external storage.
The Raycast export password must not be stored next to the file.

## Public copy
The public GitHub repo is published as a **fresh single-commit snapshot**, not the local history:
- author set to the GitHub no-reply address (the local history carries a machine hostname);
- wallpaper images removed;
- `.patch` headers rewritten to the same no-reply address;
- scanned with `gitleaks` (history and working tree) before each push.

## What detection does and does not cover
This is **not a guarantee**.
| Check | Scope | Misses |
|---|---|---|
| Capture refusal (`SECRET_RE`, `scripts/lib.sh`) | files being captured | secrets without a recognisable keyword |
| plist cleaning | known keys (`remote_id`, `device_id`, dates, counters, `SU*`, usage, window positions) | any other neutral-named identifier |
| `gitleaks` | full history + tree | short or unusual secrets, binaries (kit PDF) |
| e-mail / IP / `/Users/…` search | tracked text files | personal data written in prose |

If a secret is ever committed: do not display it, revoke/rotate it at the source, then rewrite local history
(`git filter-repo`) and republish the public snapshot.
