# Ghostty

Terminal emulator.

- **Install:** Homebrew cask (`homebrew/Brewfile`).
- **Config:** generated by Home Manager, `programs.ghostty` in `home-manager/theme.nix` (`package = null`, so Homebrew
  keeps the app). Colours come from Stylix (`theme = stylix`); font size 13, padding 12/10, background blur on.
  No config file is captured in this repo; do not keep a hand-written `~/.config/ghostty/config.ghostty` (Ghostty would read it too).
- **Apply:** `home-manager switch`; check with `ghostty +validate-config`.
- After a shell change, open a new window to pick up the new environment.
